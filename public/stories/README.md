# 스토리 커버 이미지

여기에 아래 파일명으로 이미지를 넣으면 홈 화면(`/story`)의 `StoryCard`가 이모지 대신
자동으로 표시합니다(코드 수정 불필요 — `lib/stories.ts`가 이미 이 경로를 참조하고
있습니다).

- `snowstorm-lodge.png` — 눈보라 속 산장
- `school-mystery.png` — 학교 미스터리

파일이 없거나 로드에 실패하면 `StoryCard`가 자동으로 📖 이모지로 폴백합니다.
카드 비율이 `aspect-[4/3]`(가로 4 : 세로 3)이므로 그 비율에 가까운 이미지를 권장합니다
(예: 800×600 이상).
