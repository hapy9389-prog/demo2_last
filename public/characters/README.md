# 캐릭터 이미지

여기에 아래 파일명으로 이미지를 넣으면 `Avatar` 컴포넌트가 이모지 대신 자동으로 표시합니다
(코드 수정 불필요 — `lib/characters.ts`가 이미 이 경로를 참조하고 있습니다).

- `rei.png` — 레이(츤데레)
- `yui.png` — 유이(얀데레)
- `mina.png` — 미나(소꿉친구)
- `sera.png` — 세라(차분한 누나)
- `arin.png` — 아린(쿨데레)
- `luna.png` — 루나(장난꾸러기)

파일이 없거나 로드에 실패하면 `Avatar`가 자동으로 이모지(😤 / 💗 / 😆 / 😌 / 😐 / 😜)로
폴백합니다. 정사각형 이미지(예: 256×256 이상 PNG)를 권장합니다.
